# Web Programming Project-

The concept of this project is an E-library called iLectrical. The concept comes from the idea of collecting some book references while studying at college.

## Intro
This project aimed to collect some of my book references while attending many classes in my Bachelor's degree.
There are some design features on it:
1.	Homepage (showing the homepage to access the e-library and a welcome button for accessing the next page of book collections.
2.	Book collections (showing book collections in card shape and directing to have access to the link).
3.	About (showing the developer information and a little introduction about this project)
